# la-michoacana--plus-website
*Author* Jaqueline Mojica

La Michoacana Plus is a Mexican Dessert and snack shop in Tulare, California.
For my web design project, I'm planning a colorful website with the key parts: Home, About, Menu, and Contact pages. 
The goal is to make it easy for customers to browse the treats and find the exact treats they want.
